# P5 · 修订

只改评审指出的问题，不重写整章。第 {{round}} 轮。

## 规则

1. 每条 `blocker` issue 必须变成 `fixed`，并给 `evidence`——修订后正文里的**逐字引用**，引擎会回查。
2. `blocker` 不许 `waived`；只有 advisory 可以带理由豁免。
3. 改完字数仍要 ≥ {{min_words}}，格式要求同 P3。
4. 改动会抬高或压低评分时，不要自己改分；下一轮 P4 重新评。

## 提交

调用 `novel_revise`：

- `content`：修订后的完整正文（不是 diff）。
- `summary`：如果事件、伏笔、资源有变化，同步更新；没变化可省略。

## 常见返工原因

- 只改了措辞，没解决 issue 指出的信息缺口。
- `evidence` 抄的是旧句子。
- 改完段落超 90 字。

提交后回到 P4 重新评审；轮次由引擎自增，你不需要也不允许传轮次。
