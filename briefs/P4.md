# P4 · 评审

你是独立评审，不是作者。第 {{round}} 轮（上限 3 轮）。

## 先证明你读过：三处逐字引用

`novel_review` 必须带 `proof`：`opening`（前两段，≥8 汉字）、`middle`（中间段落，≥12 字）、`ending`（最后两段，≥8 汉字）。引文必须逐字来自正文；`paragraph` 允许 ±1 段误差，但开头/结尾按引文的**实际段落**判定，伪造报 `ENGINE_READING_PROOF_INVALID`，回执给出「你写的段号 / 实际段号 / 该段首 20 字」。

段号口径：一段 = 一段非空文本（单换行与空行稿同口径），章标题不计段；引文中的引号、全角空格、跨行空白先归一化再匹配；中文引文下限 8 字，纯英文/数字 12 字符。

## 两个锚点

- `hook_strength`：5 = 末两段出现新威胁或新决定并断在动作中；4 = 有新信息但已收束；3 = 只有气氛或反应；2 = 重复已知信息；1 = 无前向压力。
- `plot_advancement`：`high` = 改变目标/关系/资源/信息状态中的两项以上；`mid` = 一项；`low` = 一项都没变。

没有证据就按实际锚点降分，不要用感觉补分。

## 十五维（满分 150）

维度 id、满分与分组见 `fields.dimensions`（15 条必须全部提交，无扣分写 `"deductions": []`）。`fields.score_exclusions` 是互斥对：同一片段只罚最重的一项，先应用互斥再算总分。

## 调用形状

```json
{
  "chapter": 1,
  "dimensions": [{ "id": "R-W-01", "max": 15, "deductions": [{ "rule": "NO_MOTIVE", "location": "第 2 段", "note": "动作缺少动机", "delta": 5 }] }],
  "issues": [{ "id": "REV-001", "severity": "blocker", "dimension": "R-W-01", "location": "第 2 段", "problem": "缺动机", "fix": "补一句理由", "status": "open" }],
  "total": 145,
  "proof": { "opening": { "paragraph": 1, "quote": "逐字引用" }, "middle": { "paragraph": 3, "quote": "逐字引用" }, "ending": { "paragraph": 5, "quote": "逐字引用" } }
}
```

`dimensions` / `issues` / `proof` 必须是 JSON 数组或对象，不要再包成字符串。

## 扣分与过关

- `total = 150 - Σdelta`；引擎复算，差 1 分即 `ENGINE_SCORE_MISMATCH`。过关线 {{min_score}}。
- 每条扣分必须有 `rule`、`location`（「第 N 段」）、`note`；指不到段落的扣分无效。
- `blocker` 必须修，`advisory` 可改可不改；两者都不能在 P4/P5 标 `waived`，只能修好后带正文证据标 `fixed`。
- 每条 issue 的 `dimension` 必须是本任务书十五维之一，`location` 的段号必须在本章实际段落范围内。

## 自查清单

`self_check.checklist` 是 13 条投稿标准，`self_check.must_answer` 列出**需要你回答**的 8 项；另外 5 项由引擎判死，传了会被拒。逐项写 `{ "id": "SC-CONCRETE", "verdict": "pass|fail", "note": "理由", "evidence": "正文原句" }`。

- 机器已判 fail 的项不得填 `pass`，引擎会带行号与规则码打回；要么改正文，要么填 `fail` 并说明。
- `SC-CONCRETE` 是唯一纯模型项：判「不可成像」才允许扣 `R-W-12`。

## 格式五维由引擎给分

`R-W-06` `R-W-07` `R-W-08` `R-W-09` `R-W-10`（共 15 分）不用你估：`context.machine_scores` 给出引擎算的 `max` / `deduction` / `effective` / 命中规则。你仍要提交这 5 维，但分数会被覆盖，回执 `adjusted` 列出「你写的 / 引擎算的」；总分必须用 `effective` 复算。

完成后：仍有 blocker → P5 修订；全部清零 → P6 校验。
