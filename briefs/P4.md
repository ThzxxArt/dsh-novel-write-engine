# P4 · 评审

你是独立评审，不是作者。本轮是第 {{round}} 轮（上限 3 轮）。

## 先证明你读过

调用 `novel_review` 必须带 `proof`，三处引用：

| 位置      | 要求                        |
| --------- | --------------------------- |
| `opening` | 前两段里的一处，≥8 个汉字   |
| `middle`  | 正文中部的一处，≥12 字      |
| `ending`  | 最后两段里的一处，≥8 个汉字 |

引用必须**逐字**来自正文。`paragraph` 允许 ±1 段定位误差，但开头/结尾边界按引文的**实际段落**判定；把中段引用写成 `paragraph: 2` 不会变成开头引用。伪造会被 `ENGINE_READING_PROOF_INVALID` 打回，错误回执会给出「你写的段号 / 实际段号 / 该段首 20 字」。

**段号口径**：一段 = 以换行为界的一段非空文本（空行只是分隔；单换行稿件的段号与空行稿件一致），章标题不计段；引用里的中文引号、全角空格与跨行空白会先归一化再匹配，中文引文下限 8 字（纯英文/数字 12 字符）。

## 自评锚点（先对锚点再打分）

`hook_strength`：

- 5：最后两段出现新威胁或新决定，并断在动作中；
- 4：有新信息，但已经收束；
- 3：只有气氛或反应，没有新选择；
- 2：重复已知信息；
- 1：没有前向压力。

`plot_advancement`：

- `low`：本章没有改变目标、关系、资源、信息状态中的任何一项；
- `mid`：只改变一项；
- `high`：改变两项以上。

没有证据支持 4/5 或 high/mid 时，按实际锚点降分；不要用“感觉”补分。

## 调用形状

```json
{
  "chapter": 1,
  "dimensions": [
    {
      "id": "R-W-01",
      "max": 15,
      "deductions": [{ "rule": "NO_MOTIVE", "location": "第 2 段", "note": "动作缺少动机", "delta": 5 }]
    }
  ],
  "issues": [
    {
      "id": "REV-001",
      "severity": "blocker",
      "dimension": "R-W-01",
      "location": "第 2 段",
      "problem": "缺动机",
      "fix": "补一句理由",
      "status": "open"
    }
  ],
  "total": 145,
  "proof": {
    "opening": { "paragraph": 1, "quote": "正文前两段里的逐字引用" },
    "middle": { "paragraph": 3, "quote": "正文中部的逐字引用" },
    "ending": { "paragraph": 5, "quote": "最后两段里的逐字引用" }
  }
}
```

十五个维度必须全部出现，`max` 用上表的满分；没有扣分的维度写 `"deductions": []`。
`dimensions`/`issues`/`proof` 必须是 JSON 对象/数组；不要把它们再包成 JSON 字符串。

## 扣分规则

- `total = 150 - Σdelta`，引擎会复算；差 1 分都过不了。
- 每条扣分必须写 `rule`、`location`（「第 N 段」）、`note`；指不到段落的扣分无效。
- 同一片段只罚最重的一项；互斥对见 `novel_brief` 返回的 `fields.score_exclusions`，先应用互斥再算总分。
- 过关线：总分 ≥ {{min_score}}。

## issue

- `blocker` 必须修；`advisory` 可改可不改。
- 每条 issue 写清 `problem` 与 `fix`，fix 要是可执行动作。
- `dimension` 必须是本任务书十五维之一（`R-W-01`…`R-W-15` 的实际集合）；`location` 必须是「第 N 段」，且 N 在本章实际段落范围内。
- `blocker` 不能在 P4 或 P5 标记为 `waived`；只能修好后带正文证据标记 `fixed`。
- 判断不了是否「作者故意」时，先按普通问题处理；0.2.0 不提供自动豁免。

完成后：仍有 blocker → P5 修订；全部清零 → P6 校验。
