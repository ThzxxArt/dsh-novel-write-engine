# P3 · 初稿

本阶段只做一件事：把 P2 的节拍写成正文。

## 硬指标

- 字数 ≥ {{min_words}}（引擎口径：汉字 + 英文单词 + 数字 + 标点）。
- 单段 ≤ 90 字；段与段之间空一行。
- 对话只用英文直引号 `"`；禁弯引号、禁全角分号、禁 `...`。
- 不写 Markdown：禁 `#`、`**`、`---`、`>`、表格。
- 不写「Day 1」「第X卷」「读者」「作者」这类出戏标签。

## 写法

1. 一段一个信息点。先动作，后反应，最后才允许一句心理。
2. 对话要有区分度：不同角色说话的句长、口头禅、攻击性不同。
3. 每 600 字左右至少一个爽点或新信息，不许连续铺垫。
4. 结尾断在动作中间或新信息刚落地时。

## 提交

调用 `novel_write_draft`，除正文外必须给全 `summary` 十个字段：

`events` / `characters_appeared` / `foreshadows`（planted/advanced/resolved）/
`new_elements` / `resource_changes` / `opening` / `continuity` /
`hook_strength`（1~5）/ `pleasure_points` / `plot_advancement`（high|mid|low）

## 提交前自检

先调 `novel_word_count` 看字数，再提交。门控失败会返回**全部**阻塞项，一次改完再交。

完成后管线进入 P4，下一步调 `novel_brief` 取 P4 任务书。
