# 0.3.0 规则包 v2：AI 味语气词与文风规则设计稿

> 状态：已实施（运行时 `rulepacks/default.yaml` 已升级为 v2）
> 目标版本：`0.3.0`
> 规则包版本：`schema_version: 2` / `version: 2.0.0`
> 关联：`docs/0.3.0-plan.md` §7.4 / §7.9、`docs/rulepack.md`

---

## 0. 结论先行

0.2.x 的“去 AI 味”主要靠 `soft/contextual/meta_narration` 词表和少量正则，能抓“仿佛/不禁/宛如”，但抓不住真正高频的**对话套路**：

- 角色互相点评对方的话：“这句话稳”“这句话接的漂亮”“这句话我不接”
- 记账式确认：“我记下了”“这个账我记住了”“认下来”“认你”
- 空转比较：“比之前的都重”“比刚才稳”“xx比xx沉”
- 守护套路：“睡吧，我守着”“你去，我跟”“我不拦”“回去睡”
- 导师式反问：“问别人还是问自己”“你自己掂量”
- 模板句：“行，xxx”“什么心思都写着xx上”“没接你的xxx”
- 单字评判：“稳”“很平”“很直”

0.3.0 规则包 v2 的目标不是“禁词”，而是：

> **把 AI 味从“词表命中”升级为“上下文 + 密度 + 跨章重复 + 可解释替换”的确定性判定。**

固定结论：

1. `schema_version: 2`，`version: 2.0.0`；0.2.x 规则包不兼容。
2. 新增 `lexicon.ai_tone`，7 个类别，39 条 entry，覆盖 50+ 个短语/模板。
3. 新增 9 个规则码：`AI_TONE_META`、`AI_TONE_ACK`、`AI_TONE_COMPARATIVE`、`AI_TONE_PROTECTIVE`、`AI_TONE_SOCRATIC`、`AI_TONE_TEMPLATE`、`AI_TONE_JUDGMENT`、`AI_TONE_DENSITY`、`AI_TONE_REPEAT`。
4. P3/P4 只给 advisory 与替换建议；P6/归档由 `EG-07` 升级为 blocker。
5. 元叙述出现在旁白中直接 blocker；出现在对白中先 advisory，同章 2 次升级 blocker。
6. 密度：1000 非空白字符内同一类别超过 `limit` 升级一级；不同类别 ≥3 或总命中 ≥5 触发 `AI_TONE_DENSITY` blocker。
7. 跨章重复：同一 entry 连续 2 章出现，或 10 章内出现 ≥3 次，触发 `AI_TONE_REPEAT` blocker。
8. 误报豁免：动作语境、具体计量比较、正常动作“把账记下了”不命中；每个角色允许 1 个 signature phrase，但仍计入密度。
9. `R-W-07（去 AI 味，4 分）` 是唯一评分映射；reviewer 的 deduction 必须引用 `AI_TONE_*` 规则码。
10. 默认包必须覆盖 canonical phrase list；编译期缺一条即 `RULEPACK_INVALID`。

## 1. v1 的问题

| 问题         | v1 现状                                  | 后果                         |
| ------------ | ---------------------------------------- | ---------------------------- |
| 只有词表     | `lexicon.soft/contextual/meta_narration` | 抓不住整句套路               |
| 没有上下文   | 只按 term 匹配                           | 正常动作“把账记下了”被误报   |
| 没有密度     | 单章不统计同类别命中                     | 一句话出现 5 次也不升级      |
| 没有跨章     | 每章独立                                 | 同一口头禅连续 10 章         |
| 没有模板     | 只支持 exact/regex                       | “行，xxx”“没接你的xxx”难覆盖 |
| 没有替换     | 只报错，不给方向                         | 模型只会换同义词，越换越 AI  |
| 没有评分映射 | 规则与 15 维脱节                         | 评审扣分与机检不一致         |

## 2. v2 规则包结构

```yaml
schema_version: 2
name: default
version: 2.0.0

lexicon:
  zero_tolerance: [...]
  soft: [...]
  contextual: [...]
  meta_narration: [...]
  ai_tone:
    version: 1
    categories:
      meta_commentary: { ... }
      ack_loop: { ... }
      empty_comparative: { ... }
      protective_cliche: { ... }
      socratic_trope: { ... }
      template_phrase: { ... }
      short_judgment: { ... }
    entries:
      - id: AI-META-001
        category: meta_commentary
        match: exact
        terms: [这句话稳, 这句稳, 这话稳]
        severity: blocker
        severity_in_dialogue: advisory
        scope: any
        note: '...'
        replacement: '...'
```

### 2.1 category 字段

```yaml
categories:
  meta_commentary:
    code: AI_TONE_META
    default_severity: blocker
    default_scope: narration
    limit: 0
    window: 0
    escalation: none
    note: '角色/叙述者点评句子本身，破坏沉浸'
```

| 字段               | 含义                             |
| ------------------ | -------------------------------- |
| `code`             | 规则码；全局唯一                 |
| `default_severity` | `blocker` / `advisory`           |
| `default_scope`    | `any` / `narration` / `dialogue` |
| `limit`            | 窗口内允许次数；0 表示不允许     |
| `window`           | 非空白字符窗口；0 表示整章       |
| `escalation`       | `none` / `one_level` / `blocker` |
| `note`             | 人类可读说明                     |

### 2.2 entry 字段

```yaml
- id: AI-ACK-001
  category: ack_loop
  match: exact # exact | regex | template
  terms: [我记下了, 记下了, 我记得了, 记得了, 我记住了, 记住了]
  severity: advisory
  severity_in_dialogue: advisory
  scope: any
  limit: 1
  window: 800
  cooldown_chapters: 1
  standalone: false
  exclude_if_matches:
    - '把.{0,8}记下了'
    - '在.{0,8}记下了'
  note: '记账式确认，连续出现会让人物像客服'
  replacement: '改成动作：他把日期写在纸角。'
  examples: ['我记下了。', '行，我记住了。']
  false_positives: ['他把账记下了。']
```

| 字段                           | 含义                                                |
| ------------------------------ | --------------------------------------------------- |
| `id`                           | 全局唯一，格式 `AI-<CAT>-NNN`                       |
| `category`                     | 必须存在于 `categories`                             |
| `match`                        | `exact` / `regex` / `template`                      |
| `terms`                        | exact 的字符串数组；归一化后去重                    |
| `pattern`                      | regex 的表达式；必须可编译                          |
| `template`                     | template 的句子；槽位只允许 `{xx}`、`{xxx}`、`{ta}` |
| `severity`                     | 单条默认级别                                        |
| `severity_in_dialogue`         | 对白内覆盖级别；仅 `scope: any` 时允许              |
| `scope`                        | `any` / `narration` / `dialogue`                    |
| `limit` / `window`             | 密度阈值；不填继承 category                         |
| `cooldown_chapters`            | 跨章冷却；0 表示不冷却                              |
| `standalone`                   | 只匹配独立短句；仅 `short_judgment` 允许            |
| `exclude_if_matches`           | 命中后若周边文本匹配这些正则，则豁免                |
| `note`                         | 误报/语义说明                                       |
| `replacement`                  | 可执行的改写方向，不是同义词替换                    |
| `examples` / `false_positives` | 测试与文档                                          |

## 4. 检测算法

```text
① 归一化
   - 全角/半角标点、空白、引号
   - 保留原始 offset，用于 location
② 引号分段
   - ASCII `"..."`；兼容旧稿 `“”` / `「」`
   - 标记 dialogue / narration
③ 匹配
   - exact：归一化后 includes
   - regex：编译一次，按句/段扫描
   - template：槽位转安全正则
④ 去重
   - 同一 span 多个命中，取最长；同长取 category 优先级
   - 优先级：meta > ack > comparative > protective > socratic > template > judgment
⑤ 上下文
   - narration 用 severity；dialogue 用 severity_in_dialogue
   - meta 在 narration 直接 blocker
⑥ 密度
   - 按 window 统计每类命中
   - 超过 limit 升级一级（advisory → blocker）
   - 全局 ≥3 类或 ≥5 次 → AI_TONE_DENSITY blocker
⑦ 跨章
   - 读取最近 10 章 finding
   - 同 entry 连续 2 章或 10 章 ≥3 次 → AI_TONE_REPEAT blocker
⑧ 输出
   - Finding：code / category / entry_id / location / evidence / severity / replacement
   - 写入 gate_result + review finding
```

### 4.1 归一化

- 只用于匹配，不回写正文。
- 去空白：`我 记 下 了` 与 `我记下了` 等价。
- 全半角标点归一：`，`/`,`、`。`/`.`、`！`/`!`。
- 引号归一：`“”`/`「」`/`"` 统一用于段分类。
- 保留 `offset` 映射，确保 location 能回到原文段落。

### 4.2 模板编译

| 槽位    | 正则       | 约束   |
| ------- | ---------- | ------ |
| `{xx}`  | `.{1,12}?` | 不跨句 |
| `{xxx}` | `.{1,20}?` | 不跨句 |
| `{ta}`  | `(ta       | TA     | Ta  | tA  | 他  | 她)` | 单字/双字 |

模板必须至少包含一个槽位；槽位外的字符全部 `escapeRegExp`。

### 4.3 独立短句判定

`standalone: true` 只用于 `short_judgment`：

- 整句 trim 后长度 ≤6 个码点；
- 或整句只由 term + 标点组成；
- 且不匹配 `exclude_if_matches`；
- 且不是动作/状态描述的一部分。

例：

| 文本           | 命中 | 原因                        |
| -------------- | ---- | --------------------------- |
| “稳。”         | 是   | 独立短句                    |
| “他下盘很稳。” | 否   | 动作/状态描述               |
| “声音稳住了。” | 否   | `稳住了` 豁免               |
| “很平。”       | 是   | 独立短句                    |
| “声音很平。”   | 是   | 仍在评判声音，但只 advisory |
| “很直。”       | 是   | 独立短句                    |

### 4.4 密度升级

| 类别              |                         limit | window | 超出               |
| ----------------- | ----------------------------: | -----: | ------------------ |
| meta_commentary   | 0（narration）/ 1（dialogue） |   1000 | blocker            |
| ack_loop          |                             1 |    800 | advisory → blocker |
| empty_comparative |                             2 |   1000 | advisory → blocker |
| protective_cliche |                             2 |   1000 | advisory → blocker |
| socratic_trope    |                             1 |   1000 | advisory → blocker |
| template_phrase   |                     1 / entry |   1000 | advisory           |
| short_judgment    |                             2 |   1000 | advisory → blocker |

### 4.5 跨章重复

- 读取 `reviews/ch-*/` 的 AI_TONE findings。
- 同一 `entry_id` 连续 2 章出现 → `AI_TONE_REPEAT` blocker。
- 10 章内 ≥3 次 → `AI_TONE_REPEAT` blocker。
- 角色 signature phrase 不计入 repeat，但计入 density。

## 7. 模板限制与误报

### 7.1 `行，xxx` 为什么不能一刀切

`行，走吧`、`行，先吃饭` 是正常对白。默认 `AI-TPL-001` 用受限 regex，只匹配抽象让步/评判槽位：

```text
^行[，,]\s*(认了|听你的|你说得对|你说了算|稳|重|轻|平|直)\s*[。！？!?]?$
```

`行，我认` 由 `AI-ACK-010` 单独处理，避免与模板重复。

### 7.2 `稳` 的豁免

以下不命中：

- `他下盘很稳。`
- `声音稳住了。`
- `局势稳下来。`
- `手很稳。`

以下命中：

- `稳。`
- `很稳。`（独立成句）
- `稳，比刚才稳。`（同时命中 COMP）

### 7.3 比较句的豁免

以下不命中：

- `这块铁比那块重三斤。`
- `他比去年高了半头。`
- `这袋米比那袋沉。`

以下命中：

- `比之前的都重。`
- `比刚才稳。`
- `这句话比上一句轻。`

判定依据：比较对象是否具体、是否带计量/单位/可验证结果。规则引擎做词面判断；语义 reviewer 做二次确认。

### 7.4 角色 signature phrase

每个主要角色允许 1 个 signature phrase：

- 必须写在 `bible/characters/<slug>.yaml` 的 `voice.signature_phrases`。
- 每章最多 1 次。
- 不计入 `AI_TONE_REPEAT`，但计入 `AI_TONE_DENSITY`。
- 超过 1 次按普通 AI_TONE 处理。

## 8. 与类型体系的关系

规则包的 `genres` / `genre_majors` / `tag_profiles` 按 `docs/0.3.0-genres.md` 的 ID 建 profile：

```yaml
genres:
  fantasy.xianxia: { profile: { foreshadow_min_dormancy: 2 } }
genre_majors:
  fantasy: { profile: { foreshadow_dormant_after: 20 } }
tag_profiles:
  world.eastern_cultivation: { profile: { lexicon_add: [灵气, 丹田, 筑基] } }
```

优先级 `tag > sub > major > global`；同一组标签对同一键冲突时保存/编译拒绝。AI_TONE 的 `lexicon_add/remove` 走同一 profile 通道，不允许标签直接改规则码或门控语义。

## 9. 门控与评分

| 阶段          | 行为                                                              |
| ------------- | ----------------------------------------------------------------- |
| P3 draft      | 只返回 advisory + replacement；不阻塞写手                         |
| P4 review     | critic-prose 必须读取 AI_TONE findings；R-W-07 扣分必须引用规则码 |
| P5 revise     | brief 附“本章 AI 味清单 + 替换建议”；revise 后重跑                |
| P6 check      | `EG-07` 评估；blocker 阻断 `ready_to_archive`                     |
| P8/P9 archive | 仍有 blocker → 拒绝归档                                           |

评分规则：

1. `R-W-07（去 AI 味，4 分）` 是唯一映射维度。
2. 存在 `AI_TONE_META`（narration）或 `AI_TONE_DENSITY` 时，review 的 `R-W-07` 至少扣 1 分；否则 `PG-07` 拒绝。
3. 每条 deduction 必须写 `rule: AI_TONE_*`、`location`、`note`。
4. reviewer 不能把 blocker 标成 waived；只能修或保留 blocker。
5. 规则引擎不直接改总分；总分仍由 `total = 150 - Σdelta` 决定。

## 10. 编译期断言

`compileRulepack` 对 `ai_tone` 新增：

1. `schema_version === 2`，`version` 非空。
2. `categories` 必须包含 7 个固定类别。
3. 每个 category 的 `code` 必须属于 `ALL_RULE_CODES`，且全局唯一。
4. entry `id` 全局唯一，格式 `AI-<CAT>-NNN`。
5. exact `terms` 归一化后必须非空、唯一、无重复跨 entry。
6. regex `pattern` 必须可编译，长度 ≤200，禁止明显灾难性回溯（嵌套量词）。
7. template 只允许 `{xx}`、`{xxx}`、`{ta}`，至少一个槽位，槽位外字符安全转义。
8. `severity` / `severity_in_dialogue` ∈ `{blocker, advisory}`；`scope` ∈ `{any, narration, dialogue}`。
9. `limit` 非负整数；`window` 正整数；`limit > 0` 时 `window > 0`。
10. `standalone` 只允许 `short_judgment`。
11. `exclude_if_matches` 每条正则必须可编译，长度 ≤200。
12. 默认包必须覆盖 `tests/fixtures/ai-tone/canonical.txt` 的全部短语；缺一条即 `RULEPACK_INVALID`。
