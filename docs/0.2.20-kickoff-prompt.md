## 2. 已锁定决策（不再讨论，按此实现）

### D1 · 引号：项目声明式

`novel.yaml` 新增可选字段 `quotes: ascii | curly`，**缺省 `ascii`**。

| 场景 | `ascii` | `curly` |
| --- | --- | --- |
| `"你来了。"` | 通过 | `ILLEGAL_QUOTE` |
| `“你来了。”` | `ILLEGAL_QUOTE` | 通过 |
| `「你来了。」` | `ILLEGAL_QUOTE` | 通过 |
| `"你来了。”`（同段混用） | `ILLEGAL_QUOTE` | `ILLEGAL_QUOTE` |
| `"你来了。`（未闭合） | `QUOTE_UNBALANCED` | `ILLEGAL_QUOTE` + `QUOTE_UNBALANCED` |
| 多段引用：段1 `“他说，` / 段2 `“别走。”` | 按 ASCII 偶数判定 | 通过（续段合法） |

要求：

- `ILLEGAL_QUOTE` 只拦「与声明风格不符」与「同段混用」，不再无条件拦中文引号。
- `QUOTE_UNBALANCED` 改风格感知的**跨段状态机**：段首开引号记 pending，续段再次以 `“`/`「`/`『` 开头视为继续，章末仍未闭合才报。
- PG-04 的提示语按项目风格生成，不再固定写「must use ASCII double quotes」。
- `briefs/P3.md` 的引号句改成 `{{quotes_rule}}` 占位符，由项目设置渲染；`briefs/P6.md` 同步。
- `novel_init` 增加可选 `quotes`；`novel_amend` 可改一次并写 journal（`quotes_changed`）；已归档章不回算。
- 不做「自动把 `“”` 改成 `"`」——不许静默改作者文字。

### D2 · PG-10 分级：只升时间倒退

| 跨章规则 | 默认 | `strict_cross: true` |
| --- | --- | --- |
| `DUPLICATE_PARAGRAPH` | blocker | blocker |
| `TIME_REGRESSION` | **blocker（新）** | blocker |
| `FORESHADOW_DORMANT` | advisory | advisory |
| `FS_REVISITED_TOO_SOON` | advisory | advisory |
| `RESOURCE_MISMATCH` | advisory | **blocker** |
| `LOCKED_DETAIL_DRIFT` | advisory | **blocker** |

要求：`RuleContext.strictCross?: boolean` + 一个 `crossSeverity(code)` helper；`runCheck`（P6）与 `runRules`（PG-10）必须传同一个值、得到同一结论。项目字段 `strict_cross: boolean`，缺省 false，可 `novel_amend` 切换。`TIME_REGRESSION` 不提供关闭开关。

### D3 · 段长：CJK 字数 + 150

- `LONG_PARAGRAPH` 计数单位改为 **CJK 字数（标点不计）**。
- 规则包 `format.paragraph_max_words` 默认值 `90 → 150`；键名不变，语义写进规则包注释与 docs。
- `WordMetrics.paragraph_max_words` 同步改成 CJK 口径，避免 `novel_word_count` 与规则两套数。

## 4. 测试要求（每个行为改动都要走完）

1. **先红**：写测试 → 跑 → 记录命令与失败输出。失败原因必须是「目标行为不对」，不是语法错误、缺导出、夹具写错。
2. **再绿**：最小实现 → 同一条测试转绿 → 跑同文件全套。
3. **能变红**：这条测试在旧实现上必须红。做不到，说明它没测到行为，重写。
4. **边界三件套**：正例（该报的报）、反例（不该报的不报）、误报例（以真实稿为蓝本做去标识化改写：换人名/地名/器物名，保留句式与标点；不许缩成 7–15 字合成短串，也不许直接收录未发表正文——仓库会随 npm 包公开）。
5. **规模**：改读模型、任务书、规则，都要跑 `check:scale` 对应断言。
6. **完成标准**：

   ```bash
   corepack pnpm typecheck && corepack pnpm lint
   corepack pnpm test
   corepack pnpm test:coverage
   corepack pnpm check:scale
   corepack pnpm check:errno
   corepack pnpm check:crash
   corepack pnpm check:docs
   ```

   全绿才算完成；任何一条红，不许用「其余都绿」汇报。
