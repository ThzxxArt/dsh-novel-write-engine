# 0.2.5 真实模型证据

## 1. 结论

2026-10-30，在 DSH + Node 24.19 环境，通过 `apihub.agnes-ai.com` 的 `agnes-2.5-flash` 与 `agnes-3.0-flash` 各生成一篇中文小说正文。两篇正文都由 0.2.5 引擎按以下真实路径处理：

```text
initProject → P1 brief/world plan → P2 brief/chapter plan → P3 brief
→ 真实模型正文 submitDraft → P4 review → P6 brief/check
→ P8 brief/archive → status done
```

§4 的离线重放使用确定性 P1/P2/P4/P6/P8 夹具（与 0.2.3/0.2.4 证据口径一致），P3 正文是真实模型输出；§2 的发布前实跑则 P1/P2/P3 都是实时模型输出。两组都通过 PG-03/04/05/06/13、P4 评审、P6 五个语义项和 P8 归档，最终 `score=145`，`stage=done`。

## 2. 发布前全链路（实时模型，临时项目）

发布 review 另跑了一轮实时链路：模型真实生成 P1 世界计划、P2 章节计划和 P3 正文，公开 `EngineService` 完成 P4 评审、P6 校验与 P8 归档；P4/P6/P8 仍用确定性夹具，不冒充模型判断。

| 模型 | 全链路结果 | 备注 |
| --- | --- | --- |
| `agnes-2.5-flash` | `stage=done`，`score=145`，正文 501 字 | P1/P2/P3 为实时输出；P2 的节拍/角色名和段落做格式归一化 |
| `agnes-3.0-flash` | `stage=done`，`score=145`，正文 486 字 | P1/P2/P3 为实时输出；P1 缺省字段与段落做格式归一化 |

实时输出经过测试驱动的**格式归一化**（JSON 字段补默认、段落重分、cast 过滤到 P1 已声明角色、常见 AI 套话替换），没有放宽任何引擎门控；引擎仍拒绝过短、超长段、零容忍用词和非法 cast。成功实跑的会话日志保存在工具结果中，临时工程不提交仓库。

## 3. 模型与输入

| 模型 | 生产接口 | 输出文件 |
| --- | --- | --- |
| `agnes-2.5-flash` | `https://apihub.agnes-ai.com/v1/chat/completions` | `tests/fixtures/agnes-025/agnes-2.5-flash.md` |

提示词要求：第三人称、主角“他”、七段、第一段逐字包含“风从窗缝里挤进来，把桌上的纸吹得翻了一页。”、旧办公室/无名信封/暗红蜡印/拆信/赴约；禁止 Markdown、引号、破折号、省略号、数字、英文字母。

模型输出仅做**换行归一化**（把单换行段落分隔为 `\n\n`），不增删、不改写任何句子。测试文件 `tests/real-model-025.spec.ts` 直接在公开 `EngineService` 上重放两篇正文，不调用网络，保证可离线复现。
