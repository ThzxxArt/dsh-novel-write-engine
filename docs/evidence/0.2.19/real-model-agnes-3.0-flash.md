## 5. 驱动做了什么、没做什么

- **没做**：改写正文、摘要、评审或语义判断；放宽任何门；跳过任何阶段。
- **做了（披露）**：`timeline` 缺行时按 `summary.events` 补 `{action:"created"}`（账本必填，引擎会把没有声明的事件判成 incomplete）；评审里五个格式维度的 `deductions` 提交前清空（引擎本来就会覆盖）。
