## 3. 真实模型

`agnes-2.5-flash` 与 `agnes-3.0-flash` 在 0.2.4 构建的临时项目跑 P1→P8、归档、report/doctor/panel v5、六种导出、`novel_reopen` 与重新归档。P1/P2/P3 为真实模型输出；P4/P6 为确定性夹具。

详见 [0.2.4 真实模型证据](0.2.4-real-model-evidence.md)。

## 4. 边界

- `novel_outline_import` 仍是显式全量导入（带 dry_run），不属于“部分提交”路径。
- `novel_amend` 仍允许显式整份 outline 修复；必须带 reason，属于维护入口。
- 不自动迁移旧项目；`outline.yaml` 格式不变。
- 真实模型 P4/P6 不是模型评分；工具结果中的 `x-semantics` 以参数描述和本地契约表承载，因为 DSH 的强制 JSON Schema 子集拒绝未知 `x-*` 关键字。
