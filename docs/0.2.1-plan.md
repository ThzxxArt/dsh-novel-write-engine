# dsh-novel-write-engine 0.2.1 迭代方案：可信账本与可回看历史

> 状态：已完成并通过全量代码功能 review 收口（本地验证）。目标版本 `0.2.1`。本文件是 0.2.1 的范围声明。
> 原则：不加新的创作功能；先让指标、失败、历史、计划与质量门禁说真话。

## 1. 问题来源

0.2.0 在真实项目《1971从偷渡港岛开始》第 1 章暴露 19 条问题，集中在六个所有权错误：

1. 大纲覆盖率在 `outlineSummary` 与 doctor 各算一套，真实项目 40/800 卡却报 100%。
2. 字数含标点，但门控、简报、状态没有分解；中文弯引号被算成英文标点。
3. gate/delta 拒绝发生在事务之前，journal 只有 committed，审计答不了“为什么被拒”。
4. 评审/校验/废弃稿使用固定路径，每轮覆盖上一轮；备份只有计数，没有列表和恢复入口。
5. P5 修订把 summary 写回 P2 计划，计划不再是提交时的证据。
6. advisory 混在 violations；对话比例配置无人消费；数字算术无检查。

## 2. 工作包

### WP0 面板可滚动

- `nwe-root`：`height:100%; min-height:0; overflow-y:auto; overflow-x:hidden; overscroll-behavior:contain; scrollbar-gutter:stable`。
- 弹框保持 `position:fixed`，Esc/遮罩/焦点返回/移动端滚动不回归。
- 测试断言根容器 CSS；真实宿主 700px 高窗口人工验证。

### WP1 指标、字数与角色

- `outlineSummary(document, archivedCount, target, archivedNumbers?)` 唯一计算：total/planned/archived/target/missingCards/plannedCoverage/archivedCoverage/cardCoverage/coverage 兼容别名；`cardCoverage` 按已归档章逐章匹配 archived 卡，不再用卡数/章数近似。
- status/report/doctor/panel/stats/命令全部消费同一结果；缺卡数单独输出。
- `WordMetrics.punctuation_chars`；PG-03 失败分解汉字/标点/英文词/数字；brief 增加 `word_count_policy`、`dialogue_ratio_target`。
- 中文弯引号、破折号、省略号归入中文标点；对话行按 `"“”「」『』` 统计。
- 剩余字数按实际平均，另保留最小目标口径。
- 初始化缺 author/description 返回 warning。
- 角色 role 从显式值、P1 计划、worldbook、narrator 推导，规范化主角/配角/反派/extra。
- insight 的 cast/维度排序改用 `compareText`。

### WP2 失败可审计

- `mutate` 在进入项目锁后、事务前被 gate/delta/state 拒绝时追加 `status:"aborted"`、`attempt:true` journal 行，带 code/reason/hint/blocking；锁前纯参数形状错误不写 journal。
- `AuditRow` 增加 seq/code/reason/hint/stage/attempt/blocking。
- `novel_audit` 支持 chapter/op/status/since/until/cursor，limit 上限 1000。
- 内容文件零写入；journal 是唯一新增证据。

### WP3 历史与备份

- `history/{reviews,checks,chapters,deprecated,plans}/chNNN.rNNNN.*` 保存前版本。
- `novel_state {kind:"history"}` 列表；带 chapter+revision 返回文本。
- `ChapterRecord.rounds`（含 lifetime `rollbacks`）/`final_check`/`archived_at`；`BookReport.effort` 输出每章难度。
- 事务备份写 `manifest.json`；P2/P4/P6 在旧文件存在时也建备份；`novel_state {kind:"backups"}` 返回 op/chapter/revision/files/reason；`novel_reopen` 的 journal/manifest 记录被重开章。
- 新增 `novel_restore`：只恢复活动章，已归档章先 reopen，恢复本身再建备份且不 replay；计划/评审/校验从真实事务 pre-image 恢复。

### WP4 计划、摘要、修订、简报

- `PipelineState.draft` 保存活动章 title/scene/narrator/summary/content_hash；P2 计划不再被 P3/P5 写入 summary，旧项目回退读 plan.summary。
- `ForeshadowDelta.anchor` 与 summary planted anchor；无 anchor 时 title 仍须逐字命中。
- `novel_revise` 支持 `patch:{expected_hash,edits}`；hash 不匹配、锚点不唯一/越界都零写入。
- `state/briefs.yaml` 保存 receipt；重复 digest 直接 replay；rollback 不再无条件清空收据。

### WP5 质量门禁

- `CheckDocument.machine.violations` 只放 blocker；`advisories` 单独；`acknowledged` 只记录 advisory。
- 新增 `DIALOGUE_RATIO`（含引号行/非空行）、`NUMERIC_CONTRADICTION`（距离/时间/速度，固定 advisory：中文主语不明确，不能把不同对象当同一运动）、`NUMERIC_FACT_MISMATCH`（只匹配“别名+数字+声明单位”的相邻写法）。
- worldbook 支持 `facts: [{alias,value,unit,tolerance?,note?}]`，并进入计数、brief 上下文、搜索与检查。

### WP6 发布与文档

- 版本 0.2.1；panel payload v3；工具 27→28（`novel_restore`），操作 31→32。
- 发布提交必须包含 `src/engine/history.ts`、`tests/021.spec.ts`、`docs/0.2.1-plan.md`、`docs/0.2.1-real-model-evidence.md`；从干净 checkout 构建前确认这四个文件已纳入版本控制。
- README/DESIGN/CHANGELOG/docs/tools/skills/面板教程同步。
- 全量 typecheck/lint/test/coverage/build/pack/host 门禁。

## 3. 验收

- 40/800 项目：规划覆盖 5%、归档覆盖 0.125%、缺卡 760。
- 2697 字：total/汉字/标点三处一致。
- 被拒 gate/check/archive 在 `novel_audit` 可见且带 code。
- 6 评 5 检 3 回滚在 `history/` 可回看；report 维度 samples > 1；effort 保留本章轮次。
- P5 前后 P2 计划 hash 不变；patch 成功与三种失败路径。
- advisory 不混入 violations，acknowledge 生效；数字矛盾以 advisory 报出，单字 anchor 被拒绝。
- 700px 高面板可滚到教程底部。
- 0.2.0 的 625 基线全绿，0.2.1 当前 667 条测试；typecheck/lint/build/pack/host 全绿。

## 4. 边界

- 数字检查能抓算术矛盾与 worldbook 声明的数字 canon；外部史实库/RAG 不在 0.2.1。
- 历史文件不自动删除；列表按 chapter/revision/kind 排序，保留完整证据。
- 真实浏览器 700px 与移动端视觉验收仍需人工；自动测试覆盖 DOM 与宿主挂载。
