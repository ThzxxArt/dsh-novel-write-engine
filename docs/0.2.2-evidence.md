## 1. 交付范围

- 删除进程内 `lastRoot`，新增按 DSH `SessionId` 的 `stateDir/session-bindings.yaml`。
- 四层选择：显式 `project_root` → 会话绑定 → cwd 有限工作区 → 唯一注册项目/配置 `projectRoot`；多项目 Agent 上下文返回 `ENGINE_PROJECT_AMBIGUOUS`。
- 注册表 v1 兼容新增 `created_at`；重复注册幂等；显式替换返回 `replaced:true`。
- 删除/移动/替换：`PROJECT_MISSING` / `PROJECT_IDENTITY_MISMATCH`，不回退、不重建、不清登记/绑定；事务在 root 消失时 abort 且不重建。
- `/novel projects|current|use|unbind|scan|resume`；scan/resume 不进入工具 schema；`use` 成功后 best-effort 登记。
- 面板 payload v4、项目选择器、choose/missing、完整卷、复制续写、请求竞态与 localStorage 回退；silent 轮询不中止可见加载。
- damaged 项目只读修复：不把占位标题/epoch `created_at` 写进绑定或注册表；`register/activate/use` 对 damaged fail-closed。
- 根路径为符号链接时仍按项目处理；工作区发现按 cwd → cwd/novel → 唯一可读子目录短路，damaged 不参与工作区候选。
- 文档、版本、`REMOTE_VERSION=4`、`package.json=0.2.2`。

### 2.1 审查补充回归

- damaged 项目：显式读取不覆盖旧绑定，`register/activate/use` fail-closed；修复后旧绑定仍可用（`tests/project-selection.spec.ts`）。
- 符号链接根：`status` 写绑定后无 root 复用、`/novel use` 与面板登记均可用（`tests/project-selection.spec.ts`、`tests/scan-workspace.spec.ts`）。
- 工作区优先级：cwd → cwd/novel → 唯一可读子目录；damaged 不参与工作区候选（`tests/scan-workspace.spec.ts`）。
- `/novel use` 成功登记；面板 silent 轮询不中止可见加载（`tests/selection-commands.spec.ts`、`tests/client.spec.ts`）。
- 事务 root 在 rename 之间消失不重建；注册表/绑定错误分支与扫描单条写失败有回归（`tests/txn.spec.ts`、`tests/bindings.spec.ts`、`tests/registry.spec.ts`、`tests/scan-workspace.spec.ts`）。

### 2.2 第二轮全量 review 补强

- **amend 保留 Selection**：`novel_amend` 不再把已解析的 session/workspace 重新解析成 explicit；绑定路径被替换时返回 `IDENTITY_MISMATCH`，workspace amend 不再产生持久绑定（`tests/project-selection.spec.ts`）。
- **空 created_at 身份**：绑定有 `created_at`、磁盘项目失去它时 fail-closed，不再静默接管（`tests/project-selection.spec.ts`）。
- **写路径 MISSING**：项目锁前的 session 预检让写工具/amend 返回 `ENGINE_PROJECT_MISSING`；doctor/guide 也不再伪装成“还没有项目”。
- **元数据读快路径**：已匹配的绑定/登记不再抢跨进程 metadata 写锁；`SessionBindings.bind` 不再因 source 变化重写整个文件。
- **面板切换骨架**：切换项目时保留选择器、隐藏旧书数据与复制按钮，直到新 payload 到达；补 `AbortSignal.any` 缺失时的 10s 兜底。
- **扫描与登记**：不为已登记候选构建完整 Snapshot；新增候选若快照仍是 damaged，不写占位登记。
- **事务根身份**：staging 期间删除/替换根目录不会重建或写入替换目录；`FsStore` 写入不再用 recursive mkdir 重建缺失根。
- **面板 missing 提示**中文化并指向真实命令；`check:host` 改为从构建产物派生 28 个工具名，并校验 v4 的 `selection/projects[].state/summary.root/resume` 字段。

## 5. 验证边界

- 0.2.2 不改变 P1–P8 的正文写入、门控、归档事务或导出渲染；真实模型链路已在 0.2.2 构建上重跑，详见 [0.2.2-real-model-evidence.md](0.2.2-real-model-evidence.md)。
- 项目选择/绑定/面板是元数据与只读投影变更；所有正文写入仍经过 `EngineService`。
- 面板的 `?root=` 不读取未登记路径；选择只写 `localStorage` 与 GET query，不写 active/绑定/项目。
- 失败关闭：无显式 root 的解析遇到注册表/绑定损坏返回 schema 错误；显式 root 读取 best-effort、不更新损坏绑定；删除/替换项目返回结构化错误；事务 root 消失时不重建项目。
